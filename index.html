Oracle listener home patching

owned end to end

On shared Oracle servers, the TNS listener kept running from the oldest Oracle Home, so it never got patched and old homes could never be removed. I built the feature that moves it to the newest patched home.

Scope
API contract, workflow orchestration and a version lifecycle (active → soft-deleted → deleted) across 6 repositories
Safety
Downtime capped at 10 min; a 3-way callback separates success, rolled back and rollback failed; patching to a removed home is blocked
Result
Live on 500+ Oracle servers; stale homes can now be retired and their disk reclaimed
