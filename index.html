Oracle listener patching. On servers that host several Oracle databases, the shared listener kept running from the oldest Oracle Home. So it never got patched, and old homes could never be cleaned up. I built the feature that moves it to the newest home, including the API, the workflow, and handling for when the rollback itself fails. Downtime is capped at 10 minutes, and it now runs on 500+ servers.

Licensing. I moved licenses and the script library from belonging to one subscription to being shared across many, and added pay-as-you-go licensing. It touched 5+ services and around 50 customers. Every data migration ran with zero downtime.

Bigger disks on gp3. Our AWS storage limits were hard-coded, so anything over 16 TiB was pushed onto io2, which costs about twice as much. I raised the limit to 64 TiB / 80k IOPS and made the gp3-or-io2 choice a per-customer setting that changes without a redeploy.

Java to Go. I helped port one of our core services to Go, which took memory per pod from 1.75 GB to 100 MB. My part was the licensing APIs. I wrote a 133-test suite, ran it against both versions, and fixed the 27 issues it turned up.
